#  WebXR AR Garden

An augmented reality experience built with WebXR and Three.js. Place virtual sunflowers in your real world environment!

##  Live Demo
-- coming

##  Features
-  Place sunflowers in AR by tapping on surfaces
-  Visual reticle for surface targeting
-  Works on mobile devices (Android + iOS)
-  Beautiful UI with clear instructions
-  Animated flowers with floating effect

##  How to Use
1. Open the link on your mobile device
2. Click "Start AR Experience"
3. Allow camera access when prompted
4. Move your phone to detect surfaces
5. Tap the screen to place sunflowers!

## 🛠️ Built With
- [Three.js](https://threejs.org/) - 3D graphics library
- [WebXR API](https://immersive-web.github.io/) - AR/VR web standard
- GitHub Pages - Free hosting

## 📋 Requirements
- **Android**: Chrome 79+ with ARCore support
- **iOS**: Safari 12+ with ARKit support
- **Desktop**: Chrome/Edge with WebXR emulator
